# 🧪 Multi-Role Login Automation (Playwright)

Automated login tests across different user roles using Playwright.

## 🚀 Tech Stack
- Playwright Test Runner
- JavaScript (ES6+)
- GitHub Actions CI/CD

## 📋 Test Scenarios

✅ Positive Role-Based Logins  
✅ Negative Logins (invalid, blank fields)  
✅ Screenshot Capture on Failures  
✅ HTML Reporting  
✅ Tag-Based Filtering (Smoke/Regression)

## 🛠 Scripts

```bash
# Install all dependencies
npm install

# Run all tests
npm run test

# Run only smoke tests
npm run test:smoke

# Run only regression tests
npm run test:regression

# Show the last HTML report
npm run show-report
